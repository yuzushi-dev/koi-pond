# Pond animation: text alternative

The silent, 12-second recording shows the Koi Pond animation, cropped from a
real Cinnamon X11 desktop recording. The image contains only the pond: no
desktop icons, folders, panels, sidebars or application windows are visible.

Orange, white and grey koi made from ASCII characters swim on a dark background.
The fish turn, change direction and pass one another within a single view of
the pond.

The wallpaper and MP4 recording use the configured 16 fps setting. The looping
GIF preview is sampled at 8 fps. This clip shows the fish animation; it does
not demonstrate desktop integration, feeding, automatic pausing, login or
monitor reconnection.

There is no speech or audio track. For a non-animated view, open the
[still preview](koi-pond-demo.jpg). The [MP4](koi-pond-demo.mp4) provides
playback controls in a video player.
